## 一、删掉并行样式系统（`ef64b19`）

删了 `src/components/ui/*`（Button / Chip / Input / Switch / Segmented / Panel）与展示它们的 `#kit` 组件库页。

**起因**：用户看过 M0–M2 的成果后说「跟我们之前搭的 demo 完全是两回事」。核下去，根因是我把原型的 Tailwind 工具类**手译**成 React 组件——等于把几百个数值人工折算一遍。走形的证据：侧栏没有选中态竖条、图标是文本字形、聊天页成了占位卡片。

**定案**：组件基座回到 CSS。原型的 CSS **逐值原样移植**成组件类（`globals.css` / `settings.css` / 后续每页一个），JSX 直接用同一套类名。**理由**：原型本身就是可点击的组件库，所有组件、所有状态都在里面，而且是视觉唯一基准；再包一层 React 就多出第二套并行样式系统，而"两套东西慢慢不同步"正是这次事故的成因。**少一套就少一处漂移源。**

**代价明说**：没有 props 层类型约束，靠类名约定。用一条纪律换掉一层抽象。

原因写进了 DESIGN-SPEC §9.3 并标注「不要再建 `components/ui/`」——否则下次还会有人加回来。

## 二、M3 文件管理（`af3524b`）

新增 `src/styles/files.css`，仍逐值移植。守住三条容易做错的边界：

### 顺带修掉三处文案失真

都是"实现时以为对、一核原型就不对"这一类：

1. **原型的「AI 自动总结」没跟着 ADR-0007 改名**。该 ADR consequence 3 明写"规格书与原型同步"，规格书改了、原型漏了。已改回「周期回顾」；同一条 consequence 4 禁止用"总结"含糊指代两边，而侧栏那句「数据回顾与 AI 自动总结」正好犯这条——原型与 `routes.tsx` 都改，新文案「知识资产与周期回顾」取自本页自己的两个面板名（**新拟提案，未经设计评审**）
2. **`routes.tsx` 把原型里两套文案压成了一条**。原型侧栏 `.nav-text small` 与页头 `.p-desc` 是**两句不同的话**（侧栏讲"这页干什么"、页头讲"你能看到什么"），压成一个字段后页头显示的是侧栏那句——**四处里错了三处**。已拆成 `desc` / `pageDesc`
3. **`.stagger`（L2 BlurFade 错峰入场）整个没移植过**。之前没有页面用到它所以没暴露。已补进 `globals.css`
