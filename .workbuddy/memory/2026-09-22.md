## 动效库选型决策（用户问 Magic UI vs react-bits）
- 结论：不二选一，**Magic UI 做主力、react-bits 做限量补给**；若必须二选一 → Magic UI。
- 依据：Magic UI 是 shadcn 伴生库、源码可拥有、Tailwind+Motion 单引擎，能与设计 token 对齐；react-bits 是展示型动画集市，各组件依赖 GSAP/Motion/Canvas 混杂，常驻背景吃 GPU。
- 建立「动效三层分工」：L1 系统层原生 CSS 70% / L2 交互层 Magic UI 20% / L3 氛围层 react-bits 10%（仅首页 AI 球与空状态）。
- 推荐技术栈：React + Vite + Tailwind + shadcn/ui。项目当前无 package.json，栈尚未落地。
- 决策与红线已写入 `.impeccable.md`（含禁用 Meteors/Particles 等网红特效）。

## 动效验证版 v0.2（用户选「混合使用，先做一版看效果」）
- 产出 `design/prototype/index-v2.html`（v0.1 保留不动，便于对比）。
- 关键手法：用原生 CSS/JS **复刻** Magic UI 与 react-bits 的代表动效，先定手感，再迁移 React 正式栈。
  - L2 复刻：NumberTicker 数字滚动、AnimatedBeam 流光（进化图谱 + 关联图边）、BlurFade 错峰入场、BorderBeam 边框光、Dock 悬停放大联动、Spotlight 卡片光斑、ShimmerButton、TypingAnimation 占位打字机。
  - L3 复刻：首页极光氛围（bounded 区域，非全页常驻）、AI 生命体轨道环 + 轨道点、ClickSpark 点击火花、Magnet 磁吸悬浮球。
  - L1：pageIn 页面切换（blur+位移）、列表与卡片 stagger。
- 新增**动效密度三档开关**（全开 / 克制 / 关闭），默认「克制」= 关掉 L3 只留 L1+L2，供用户亲手选定最终密度。
- 技术要点：缓动统一 easeOutQuart，不用弹性回弹；SMIL animateMotion 实现流光；BorderBeam 用 conic-gradient 旋转 + overflow 裁切；进度条/热度柱每次进入归零重播。

## v0.5：配色黄金律（中性面由主色派生）+ 聊天窗放大
- 用户反馈：① 悬浮球聊天框太小 ② "就一蓝色为主体，背景色能否根据大师配色适配，找黄金定律搭配"。
- 产出 `design/prototype/index-v5.html` + 可复用生成器 `design/palette-gen.py`。
- **用 OKLCH 做了实测分析（关键发现）**：
  - 靛 #3B4CC0 色相 271.3°，陶 #B4551F 色相 46.3°，夹角 135.0° —— 与黄金角 137.5° 仅差 2.5°，即原配色本身就是黄金角关系。
  - 但背景完全没跟上：米黄底 #F4F3EF 色相 95.1°（与靛蓝差 176°，近乎正对）；深色底 #101312 色相 173.7°（那是配 v0.3 青 Jade 的，与靛蓝差近 100°）。**这就是"冷主色坐在暖米黄上"违和感的根因。**
- **确立「配色黄金律」三条**：律1 面积比 60:30:10；律2 中性面与主色同色相、彩度≤0.014、只动明度；律3 点缀色 = 主色 + 137.5°（黄金角）。
- 由这三条重算全部 token：靛/白天 底 #EFF1F7 墨 #161821 主 #3B4CC0 缀 #B35618；靛/黑夜 底 #0D0F15 主 #88A0F6 缀 #E58C5B。
- 新增 `<html data-accent="gold|terra">` 开关：点缀色可选「黄金角派生」或「锁定陶色」，侧栏原型控件里可现场对比。
- 设置页新增「配色黄金律」说明面板（三条律 + 面积比条 + 实时色相数值）。
- 聊天窗 356×540 → **440×640**，正文字号 12.5→13.5px，头像/内边距/输入框同步放大。
- 对比度：3 主色 × 日夜 = 6 组、每组 9 项全部 ≥ WCAG AA（脚本自动校验，非目测）。
- 技术要点：写 `palette-gen.py` 实现 sRGB↔OKLCH 双向转换 + 色域外二分压彩度；token 段由脚本整体替换，不手工改色值。
