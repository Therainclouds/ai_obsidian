# 只有走一次演化的才是实体，视图不进图谱

一轮收敛里同时冒出三个含混点。它们看起来无关，其实是同一个问题的三个面——**什么算内容实体**：

- **对话**能当知识点的来源，但按定义"来源关系"只能是 `知识点 ← 素材`。那它是不是素材？
- 总结页的**日/周/月条目**，和 AI 蒸馏出的**知识点**，是不是一回事？
- 文件管理里「**全部**」这个筛选胶囊，数的是素材还是素材 + 知识点？

不回答这个问题，数据模型没法动：`kind` 要不要加值、图谱收录什么、"来源"这个词会不会分裂成两个——全都悬着。

结论：**判定标准是"它有没有走一次演化"。** 走了的才是内容实体；没走的是**视图**——视图不进图谱、不产生来源关系、不计入统计。

## 判定标准

| 问 | 是实体 | 是视图 |
|---|---|---|
| 参与过一次**演化记录**吗（作为输入或产出）？ | 是 | 否 |
| 能出现在**来源关系**或**关联**里吗？ | 能 | 不能 |
| 进**进化图谱**吗？ | 进 | 不进 |
| 它消失时，图谱要变吗？ | 要 | 不要 |

这条标准不是新发明的，是 ADR-0001 那条不变量的直接推论：**一次演化至少产出一个实体或一条关联，产出为空的是日志不是演化**。反过来读就是——**没走演化的东西，不可能是实体**。

## 应用一 · 对话是素材的子类

**决策**：对话**是素材**（**对话素材**），与**文件素材**并列，二者只差"有没有文件夹"。

- 它**没有文件夹归属、不进文件树**，只作为**来源**出现在知识点里
- 未被蒸馏引用过的对话**不进入任何知识视图**，只活在聊天页的会话历史里
- 它**不是**「**会话**」——会话是 **agent 运行时**自己的记录（`state.db`，产品不读）；对话素材是产品自己存的领域实体

**为什么必须把它归进素材**：只要让对话成为第三类实体，「来源」就分裂成两个词（`知识点 ← 素材` 与 `知识点 ← 对话`），此后每加一种输入都要再扩一次。归进素材后，**来源关系的箭头永远只有一个方向**——这是术语纪律（同一概念只允许一个词）在数据模型上的投影。

### 备选：对话是独立的第三类实体 —— 否决

收益只是"分类看起来更整齐"；代价是来源关系的定义要变成 `知识点 ← 素材 | 对话`，且此后每引入一种输入（网页剪藏、语音、剪贴板片段）都要再扩一次。**用一个不稳定集合去定义一个核心关系，是设计债。**

## 应用二 · 周期回顾是视图，不是知识点

**决策**：总结页的日/周/月/年条目叫**周期回顾**。它是**视图**——把该时段已有的**知识点**按时间重排，并附一段 AI 写的导览文字；不落盘为文件、不产生来源关系、不进演化记录、不计入统计。

**为什么不能让它算知识点**：它的输入必然是**已经提炼过的知识点**。若它算知识点，来源关系就会出现 `知识点 ← 知识点`，而 CONTEXT.md 钉死的是 `知识点 ← 素材`；若为了圆这个说法把知识点也算作素材，那「素材」一词就同时指原始内容与 AI 产出——**等于取消「素材」这个概念**。

### 备选：周期回顾也是知识点（时间触发的蒸馏）—— 否决

理由同上。另有一条产品侧判断：周期回顾的价值是**帮我看**，不是**帮我记**。它是一次阅读，不是一次产出；把它沉成实体，图谱会从"知识怎么长出来的"变成"内容与日志的混合物"。

## 应用三 ·「全部」只数文件素材

**决策**：文件管理里「**全部**」胶囊数的是**文件素材**，数值 = 各文件夹之和；**知识点**有自己的胶囊，两个视图不重叠。

这条由 D12 直接推出：胶囊是**视图切换器**。既然「知识点」已经独立成一个胶囊，「全部」再含它就是同一个视图出现两次。而且数字会对不上——筛选条写 184、树里只有 128 个文件。

> **与 ADR-0006 不冲突**：那条说的是"「全部」**不跨空间**"（空间维度），本条说的是"「全部」**不含知识点**"（实体维度）。两个维度都要成立。

## Consequences

1. `kind` 只有两个取值：`material | distilled`。**不加第三个**——对话素材是 `material`，靠 `folderId === null` 与文件素材区分
2. 图谱的收录规则可以写死：**只收走过演化的东西**。这使"以图谱为准"这条承诺变成可检验的
3. 总结页的「AI 自动总结」全量改名为**周期回顾**，规格书与原型同步
4. 界面文案不得用"总结"含糊地指代知识点或周期回顾其中一边
5. 术语表新增**对话素材**、**周期回顾**两条，并新开「**视图层**」分节——明确标注这一节的词**不是内容实体**
